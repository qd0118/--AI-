# 经营分析与智能决策平台

**项目背景：**格拉斯哥大学国际会计与金融管理专业背景下的财务分析与 AI 应用实践  
**项目方向：**财务 BP · 预算管理 · 经营归因 · 情景测算 · Agent 报告

## 项目概览

本项目以安克创新 2024 年公开年报披露的产品收入和成本为校准依据，自主构建 2025 年模拟订单、预算、费用和应收数据，完成“预算编制—预实对比—差异归因—情景测算—报告输出”的经营分析流程。公开年报用于确定年度基准；2025 年月度经营明细和预算为本项目生成的模拟数据。

## 核心工作

1. **数据与预算体系：**使用 Python 生成 360 个产品×渠道×地区×月份的模拟经营观察单元；以 SQLite 管理经营和财务数据，通过 SQL 关联月度预算与实际，统一收入、成本和费用口径。
2. **经营差异归因：**按月比较预算与实际，将收入差异拆解为销量、产品结构和成交价格影响，将成本差异拆解为销量、结构和单位成本影响；对费用异常形成可追溯的指标依据。
3. **资源配置测算：**调整销量、价格、单位成本、营销预算分配和回款延迟等假设，比较不同情景下的收入、经营贡献及增量现金影响。
4. **可视化与 AI 应用：**通过 Streamlit 展示预实分析、情景模拟和 Agent 报告；导出 Power BI 看板所需的数据表，提供指标定义、DAX 度量值与页面搭建说明。Agent 先读取程序计算的结果，再生成含数据依据的月度经营分析初稿；可选调用 LLM 优化报告表述。

## 运行项目

需要 Python 3.10 或更新版本。在项目文件夹中依次运行：

```powershell
python -m pip install -r requirements.txt
python -m app.build_data
python -m app.export_bi
python -m streamlit run app/dashboard.py
```

终端出现本地网址后，用浏览器打开即可操作 Streamlit 看板。无需 API Key 也能生成规则化分析报告；如需使用 LLM 撰写功能，可自行配置 `OPENAI_API_KEY`，再在页面中开启该选项。

## Power BI 看板

`exports/` 包含月度损益、产品与渠道、部门费用及差异桥接表。使用 Power BI Desktop 导入这些 CSV 后，即可按 [`docs/power_bi.md`](docs/power_bi.md) 中的页面结构、字段关系与 DAX 指标搭建看板。看板页面建议包括月度经营总览、产品与渠道分析、费用差异与归因。完成后可将 `.pbix` 文件添加到本仓库，便于面试展示。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `app/build_data.py` | 生成模拟经营数据并写入 SQLite |
| `app/analysis.py` | SQL 取数、预实差异拆解与情景测算 |
| `app/agent.py` | 异常识别、证据组织与报告草稿 |
| `app/dashboard.py` | Streamlit 交互页面 |
| `app/export_bi.py` | 导出 Power BI 数据表和分析样例 |
| `data/source_manifest.json` | 公开财报校准数与模拟数据口径 |
| `docs/power_bi.md` | Power BI 建模和图表说明 |
| `tests/test_finance.py` | 数据校准与计算核对 |

## 数据口径

公开财报来源：[安克创新 2024 年年度报告](https://disc.static.szse.cn/disc/disk03/finalpage/2025-04-28/9bd3ae70-7998-4fbe-99ff-87b7ebd43cb8.PDF)。年报提供年度产品收入与成本数据，但没有披露产品×渠道×地区×月份的完整交叉明细。本项目中的该分布、单价、销量、预算、费用分配与应收回款节奏均为模拟假设。页面中的“经营贡献”按收入减成本及所列费用计算；“增量现金”仅用于比较假设变化的影响，不等同于财务报表中的经营活动现金流量。
